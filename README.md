# Untürked Emek Tanıtım

Untürked Emek Unturned sunucu ağının tanıtım sayfası: iki sunucunun sistemleri, oyun içi arayüz görüntüleri, Discord
botu, web sitesi ve altyapı. `tanitim.png` aynı sayfanın tek parça görselidir.

Bu depo bir yayın çıktısıdır; kaynak ana depoda tutulur. Arayüz görüntülerindeki oyuncu adları, oylar ve öneriler
örnektir.
